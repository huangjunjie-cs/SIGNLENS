adjacency(*, directed: bool = False, weighted: bool = False) → csr_matrix[source]#

Signed adjacency matrix.

Parallel edges are summed (sign * weight; sign alone when weighted=False). With weighted=False the result is reduced to its sign, so every entry is in {-1, 0, +1}: a pair with net-positive interactions becomes a positive tie and pairs whose interactions cancel out are dropped. The undirected version is symmetric and has a zero diagonal.

Descriptive metrics#

Descriptive signed-network statistics (the original SIGNLENS metric set).

Follows the metric set of BalanSiNG (Jung et al., EDBT 2020): sign distribution, signed degree distributions, signed triangle census, hop plot and singular value spectrum, plus the signed butterfly census for bipartite graphs.

signlens.basic.butterfly_census(bg: SignedBipartiteGraph) → dict[source]#

Exact signed butterfly (2x2 biclique) census of a signed bipartite graph.

A butterfly (u1, u2; v1, v2) is classified (up to isomorphism) by the signs (u1v1, u1v2, u2v1, u2v2):

++++ (0 neg), +++- (1), ++-- (2, negatives share a row node), +-+- (2, share a column node), +--+ (2, disjoint), +--- (3), ---- (4). A butterfly is balanced iff it has an even number of negative edges.

signlens.basic.triad_census(g: SignedGraph) → dict[source]#

Count undirected signed triangles by number of negative edges.

Uses the sign-aggregated undirected graph. With positive/negative adjacency matrices P and N:

+++ = tr(P^3)/6,  ++- = tr(PPN)/2,  +-- = tr(PNN)/2,  --- = tr(N^3)/6

Balanced triangles (Heider) are +++ and +--.

Structural balance#

Structural balance measures.

A signed graph is balanced (Cartwright & Harary, 1956) iff its nodes can be split into two camps with all positive ties inside camps and all negative ties across them – the idealised picture of a perfectly polarized society. The measures here quantify how far a network is from that state:

  • frustration() – the frustration (line) index: the minimum number of ties that violate any two-camp split (Harary 1959; Aref & Wilson 2018).

  • algebraic_conflict() – smallest eigenvalue of the signed Laplacian (Kunegis et al. 2010); zero iff balanced.

  • walk_balance() – the walk-based degree of balance of Estrada & Benzi (2014), weighting closed walks of all lengths.

The triangle-based index lives in signlens.basic.triad_census().

Smallest eigenvalue of the signed Laplacian on the largest component.

Zero iff the component is balanced; larger values mean more conflict that cannot be explained by a two-camp split. normalized=True makes the value comparable across graphs of different density (range [0, 2]).

signlens.balance.signed_laplacian(g, *, normalized: bool = False, weighted: bool = False) → csr_matrix[source]#

signlens.balance.walk_balance(g, *, beta: float = 1.0, weighted: bool = False, probes: int = 40, seed: int | None = 0)[source]#

Estrada-Benzi walk-based balance K = tr exp(beta A) / tr exp(beta |A|).

K is 1 iff the graph is balanced and approaches 0 for highly frustrated graphs; it weights every closed walk (not just triangles) by beta^k / k!. Computed exactly for small graphs and with a Hutchinson trace estimator otherwise.

Polarization#

Measuring and characterising polarization.

Polarization is not one number. SIGNLENS characterises it along four complementary axes:

  1. Structure (balance) – how close the whole network is to the ideal two-camp state; see signlens.balance.

  2. Camps – who forms the opposing camps: polarized_communities() (Bonchi et al., CIKM 2019) and the balance partition from signlens.balance.frustration().

  3. Separation – how strongly given/detected camps are divided: camp_statistics(), signed_modularity(), random_walk_controversy() (Garimella et al., 2018).

  4. Positions – a latent ideological axis: spectral_positions() (signed graphs) and ideal_points() (vote matrices), with distributional indices such as bimodality_coefficient(), group_separation() and esteban_ray().

polarization_profile() runs all of them and returns a JSON-ready dict. Node-level diagnostics are provided by node_scores().

signlens.polarization.camp_statistics(g, labels) → dict[source]#

Tie composition within vs. between camps.

Returns, among others:

  • gap – P(+ | within) - P(+ | between), in [-1, 1]; 1 = perfect polarization.

  • ei_positive / ei_negative – Krackhardt E-I index of positive and negative ties ((external - internal) / total). Polarized networks have ei_positive -> -1 and ei_negative -> +1.

  • consistency – share of ties agreeing with the partition (positive within, negative between); for the optimal two-camp split this equals 1 - frustration ratio.

  • contrast – density-based block contrast ((d+_in - d+_out) + (d-_out - d-_in)) / 2 in [-1, 1], where d are tie densities over all possible within / between pairs. Unlike the ratios above it also rewards absent cross-camp cooperation, so an all-positive network with camps that merely ignore each other scores between 0 and 1, and a consensual network scores ~0.

signlens.polarization.esteban_ray(x, labels, alpha: float = 1.6) → float[source]#

Esteban-Ray (1994) polarization of groups along an axis.

ER = sum_ij pi_i^(1+alpha) pi_j |mu_i - mu_j| with group shares pi and mean positions mu. Rewards both within-group homogeneity (identification) and between-group distance (alienation).

signlens.polarization.group_separation(x, labels, a=None, b=None) → dict[source]#

Separation of two groups along a 1-D position axis.

  • distance – |mean_a - mean_b|

  • cohen_d – distance / pooled standard deviation

  • overlap – number of members of either group positioned beyond the most moderate member of the other group (the classic “overlap count” in studies of congressional polarization); 0 = no overlap at all.

signlens.polarization.ideal_points(bg: SignedBipartiteGraph, dim: int = 1, *, min_votes: int = 20, lopsided: float = 0.025, iters: int = 50, seed: int | None = 0)[source]#

Ideal points from a signed member x item matrix (e.g. roll-call votes).

A low-rank model X_ij ~ x_i . v_j is fitted to the observed, item-centred entries by alternating least squares (initialised with SVD). Following NOMINATE conventions, lopsided items (minority share below lopsided) and members with fewer than min_votes votes are excluded (their position is nan).

Returns:#
positionsndarray, shape (n_rows,) or (n_rows, dim)

Scaled so the 98th percentile of |x| equals 1. The sign of each axis is arbitrary; use orient().

signlens.polarization.node_scores(g: SignedGraph, camps, positions=None) → DataFrame[source]#

Per-node polarization diagnostics.

  • frustrated / frustration_share – incident ties that contradict the camp structure (positive across or negative within).

  • bridging – share of a node’s positive ties that cross camps; high values flag brokers between camps.

  • dissent – share of a node’s negative ties aimed at its own camp.

signlens.polarization.polarized_communities(g, *, local_search: bool = True, max_moves: int | None = None) → PolarizedCommunities[source]#

Find two opposing communities S1, S2 maximising polarity.

Each community is internally cohesive (positive ties) and the two are mutually antagonistic (negative ties); nodes outside S1 u S2 are neutral. Spectral sweep on the leading eigenvector of A (Bonchi et al. 2019, Discovering Polarized Communities in Signed Networks) refined by local search.

signlens.polarization.random_walk_controversy(g, labels, *, k: float = 10, camps=None) → float[source]#

Random Walk Controversy (Garimella et al., TSC 2018) on the positive graph.

RWC = P_XX P_YY - P_XY P_YX where P_XY is the probability that a random walk starting at a uniformly random node of camp X is first absorbed at one of the k highest-degree nodes of camp Y. Ranges over [-1, 1]; values near 1 mean endorsement rarely crosses camp boundaries.

signlens.polarization.signed_modularity(g, labels) → float[source]#

Signed modularity of Gómez, Jensen & Arenas (2009).

Q = (2w+ Q+ - 2w- Q-) / (2w+ + 2w-); high when positive ties concentrate within and negative ties between groups beyond chance.

signlens.polarization.spectral_positions(g, dim: int = 1) → ndarray[source]#

Latent positions from the leading eigenvectors of D^-1/2 A D^-1/2.

For a polarized network the first coordinate separates the camps (its sign is the camp) and its magnitude reflects how embedded a node is in its camp. Positions are scaled to roughly [-1, 1]; isolated nodes get 0.

Projection, time and data#

Turn signed bipartite data (e.g. roll-call votes) into a signed network.

Two members are tied positively if they vote together unusually often and negatively if they vote against each other unusually often. Two rules are supported:

  • threshold – agreement rate >= pos gives +, <= neg gives -. Fixed thresholds keep networks comparable across time, which is what we want when tracking polarization historically.

  • zscore – binomial z-score of each pair’s agreement count against the overall agreement rate; |z| >= z creates a tie. This adapts to each chamber’s baseline consensus.

Synthetic signed networks with known polarization, for testing and teaching.

signlens.synthetic.polarized_sbm(sizes=(50, 50), *, p_in: float = 0.15, p_out: float = 0.08, noise: float = 0.0, neutral: int = 0, p_neutral: float = 0.05, seed: int | None = 0) → tuple[SignedGraph, ndarray][source]#

Signed stochastic block model with antagonistic camps.

Ties inside a camp are positive and ties across camps negative; each sign is then flipped with probability noise. neutral extra nodes connect to everyone with probability p_neutral and random signs.

noise = 0 yields a perfectly balanced (maximally polarized) graph; noise = 0.5 destroys all camp structure.

Returns the graph and the ground-truth camp per node (-1 for neutral).

signlens.synthetic.polarizing_process(n: int = 120, steps: int = 12, *, p: float = 0.08, start_noise: float = 0.5, end_noise: float = 0.02, seed: int | None = 0) → SignedGraph[source]#

A timestamped graph that polarizes over steps periods.

At period t the same population re-forms its ties with a noise level interpolated from start_noise (no camps) to end_noise (two hostile camps). Useful for demonstrating temporal analysis.

U.S. Congress roll-call votes from Voteview (Lewis et al., voteview.com).

Replaces the original GovTrack scraper: Voteview publishes clean member-level votes for every House and Senate roll call since the 1st Congress (1789), together with DW-NOMINATE ideal points, which we use to validate our own network-based measures.

Votes are coded +1 (Yea / paired yea / announced yea) and -1 (Nay / paired nay / announced nay); abstentions are dropped.

Polarization of the U.S. Congress, 1789 - today.

For each chamber and Congress we

  1. load member x roll-call votes from Voteview,

  2. estimate ideal points from the vote matrix (ideal_points()),

  3. project the votes into a signed co-voting network (agreement >= 70% -> +, <= 30% -> -), and

  4. measure polarization along every axis of signlens.polarization.

build_series writes one JSON per Congress plus a per-chamber time series, which the web app animates.
